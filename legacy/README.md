# Legacy Archive

Files in this directory are archived reference material from earlier pre-Next iterations of Ghosted.

- They are not part of the supported local development flow.
- They are not part of the production build or deploy path.
- The canonical app now lives in `src/app` and is built with `next build`.

If you need current casino behavior, use the Next.js implementation under `src/components/ui/CasinoGame.tsx` and `src/casino/`.
